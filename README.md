# 教练排课微信小程序

面向个人教练与会员使用的原生微信小程序。教练可以管理学员、课包、排课、取消、改期、完课、训练记录、收入和销售；会员可以绑定已有资料、查看课时和课程，并在授权范围内预约、取消或改期。

本仓库是**开发源码交接仓库**，不包含真实会员资料、数据库导出、云端备份、密钥或本机配置。

## 技术架构

- 客户端：原生微信小程序 JavaScript、WXML、WXSS、JSON。
- 本地层：微信 Storage，本地优先更新界面。
- 云端层：微信 CloudBase 云函数、数据库、回执与版本号同步。
- 一致性：稳定 requestId、幂等回执、revision、增量读取及完整读取兜底。
- 环境：Production 与 Sandbox 使用独立数据域，测试只能在 Sandbox 进行。
- 测试：`tests/` 内的永久回归测试及判别力测试。

## 本地开发

### 1. 克隆与分支

```bash
git clone https://github.com/k0820/coach-miniapp.git
cd coach-miniapp
git switch -c feature/简短任务名
```

所有修改必须通过独立分支和 Pull Request 合并，禁止直接向 `main` 推送或强制推送。

### 2. 安装云函数依赖

每个含 `package.json` 的云函数目录都独立安装依赖。不要提交 `node_modules`。

PowerShell 示例：

```powershell
Get-ChildItem .\cloudfunctions -Directory | ForEach-Object {
  if (Test-Path (Join-Path $_.FullName 'package.json')) {
    npm install --prefix $_.FullName
  }
}
```

### 3. 微信开发者工具

1. 在微信开发者工具中导入仓库根目录。
2. 本机设置由开发者工具写入 `project.private.config.json`，该文件不会提交。
3. 只做界面和自动测试时，不需要部署任何云函数。
4. 需要联调云端时，必须使用 Sandbox，并先确认当前微信账号拥有开发权限。
5. 未获得项目所有者明确授权，不得部署正式云函数、执行迁移、切换数据集或操作 Production 数据。

> `project.config.json` 中的 AppID 和 CloudBase 环境标识是项目标识，不是 AppSecret。仓库不包含 AppSecret。朋友需要由小程序管理员添加为开发者，才能使用同一小程序进行调试。

## 测试原则

- 先运行与本次修改有关的专项测试，再运行一次完整回归。
- 测试必须具备判别力：把关键逻辑故意弄错时，测试应当失败。
- 禁止测试脚本写盘修改真实源码；使用 `tests/helpers/mutate-overlay.js` 的内存覆盖方式。
- Windows 下逐个直接运行 Node 测试，不使用 `spawnSync` 串跑，避免 EBUSY 假红。
- Production 只用于正常使用和收集最少必要证据，修复必须回到 Sandbox 验证。
